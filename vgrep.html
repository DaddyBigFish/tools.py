vgrep

Local File Search Utility

To begin, select a folder to search. All processing is performed locally within your browser; no files or data are uploaded or transmitted.

For best results, select a specific folder, such as a project directory, rather than an entire drive or your user profile folder. For security reasons, your browser restricts access to broad system locations such as C:\ or C:\Users\<username>. If you encounter this restriction, copy the files you wish to search into a dedicated folder and select that folder instead.
